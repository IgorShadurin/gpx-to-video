# Краткая инструкция

Сборка: `cargo build --release`. Нужны Rust и FFmpeg с `ffprobe`.

```sh
# Все ролики камеры → новые ролики с показаниями.
target/release/gpx-to-video render --route ride.gpx \
  --video ./camera-clips --output ./finished-videos

# Настроить вид слоя без рендера видео.
target/release/gpx-to-video view

# Только прозрачное видео для монтажа.
target/release/gpx-to-video render --route ride.csv --video clip.mp4 \
  --output ./layers --overlay-only prores
```

По умолчанию русский язык, велосипедная шкала до 60 км/ч и обновление графики 15 раз в секунду. Частота и размеры исходного ролика сохраняются для поддерживаемого видео с постоянной частотой кадров. Для самостоятельного слоя без видео размер по умолчанию 3840×2160; задайте `--duration` и при необходимости `--start`.

Сперва проверьте время командой `inspect clip.mp4`. Метаданные камеры не гарантируют верные часы. `--offset -5` исправляет камеру, спешащую на пять секунд; `--timings timings.json` задаёт начало и поправки отдельных файлов. Время без часового пояса не принимается. Фактические файлы Osmo Action 6 пока не проверялись: тесты используют искусственные 4K H.264/HEVC.

`view` открывает локальный редактор: перемещение и размер блоков, цвета, русский/английский язык, показ координат, высоты, расстояния и названия дороги. Сохраните `theme.toml` и передайте `--config theme.toml`. `preview` рисует один PNG с настоящей прозрачностью. Изображение фона в редакторе не отправляется на сервер.

Карта загружается из OSM и сохраняется в кэше. Повторный запуск использует его; `--offline` запрещает сеть. Полный трек и видео никуда не отправляются, но сервер карт получает границы нужных участков. Публичный сервер может быть перегружен — завершённые загрузки останутся в кэше. Для длинных поездок можно передать собственный региональный файл `--osm-data region.json`.

Скорость берётся из измерений GPX/CSV. Между соседними достоверными точками рассчитываются промежуточные значения. Пауза и потеря GPS остаются разрывами. Неизвестная скорость показывается прочерком, а не нулём. Название дороги — ближайшая дорога в пределах заданного расстояния; населённый пункт обозначается как «окр.», поскольку это оценка близости, а не проверка административной границы.

Наложение требует перекодирования видео. Семейство H.264/HEVC, размер, постоянная частота кадров и поддерживаемая глубина цвета сохраняются; звук копируется. Для D-Log M/HDR используйте прозрачный ProRes 4444 и накладывайте его после цветокоррекции. WebM с альфа-каналом занимает меньше места, но не все монтажные программы читают его прозрачность.

Примеры и ограничения подробно описаны в основном README. Личные треки и видео в репозиторий не входят.
